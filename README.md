## How it works

- Apple storefront RSS (charts, new releases, genre charts), Google Play top charts, GitHub Search API.
- Stores do not publish download counts: rising lists use **rank movement** and **rating deltas**; `+/day` switches on once two daily snapshots exist, until then the table shows the lifetime **avg/day**.
- Star charts are built from our daily snapshots; on day one they show a size bar and switch to a line as soon as a second snapshot exists. The GitHub `stargazers` endpoint now returns 404 for everyone, so there is no historic backfill.
- Small = fewer than 5,000 ratings; big publishers, gambling, dating and VPN apps are filtered. GitHub recent-creation results are ~90% star-farm spam and are filtered.

### Files

```
data/manifest.json                    version + every shard (path, bytes, sha256)
data/rising/{apple,google}/{cc}.json  risingNow / justLaunched / hiddenGems

data/mac/{cc}.json · data/podcasts/{cc}.json
data/github/{daily,weekly,monthly,quarterly,yearly}.json
data/global/risers.json · data/alternatives.json · data/health.json
charts/spark/{owner__repo}.svg       star history per repository
```
