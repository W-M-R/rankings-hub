## How it works

- Data source: Apple storefront RSS (charts, new releases, genre charts), Google Play top charts, GitHub Search API.
- Neither store publishes download counts, so rising lists use **rank movement** and **rating deltas** as proxies; `is_new` stays off until a previous day exists.
- Small means fewer than 5,000 ratings; big publishers, gambling, dating and VPN apps are filtered out.
- GitHub windows are repositories created inside the window sorted by stars; the recent-creation feed is roughly 90% star-farm spam and is filtered.

### Data files

```
data/manifest.json                 version + every shard (path, bytes, sha256)
data/rising/{apple,google}/{cc}.json   risingNow / justLaunched / hiddenGems
data/charts/{apple,google}/{cc}.json   mainstream charts for comparison
data/mac/{cc}.json · data/podcasts/{cc}.json
data/github/{daily,weekly,monthly,quarterly,yearly}.json
data/global/risers.json · data/alternatives.json · data/health.json
```

## Run locally

```bash
npm install
export GITHUB_TOKEN=$(gh auth token)
ENABLE_GOOGLE_PLAY=true PLATFORMS=apple,mac,podcasts,google,github node tools/collect.mjs
node tools/build.mjs && node tools/validate.mjs
```

Apple throttles bursts: requests are serialised at `APPLE_RPS` (default 3/s) and minor storefronts rotate over 3 days.
